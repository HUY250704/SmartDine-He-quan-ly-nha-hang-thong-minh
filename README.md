# SmartDine Monorepo

## Structure

- `frontend/`: Vite + React + Tailwind + React Router + Axios + Socket.IO client
- `backend/`: Express + MongoDB + Mongoose + Socket.IO server

## Run

- Install dependencies: `npm install`
- Start backend: `npm run dev:backend`
- Start frontend: `npm run dev:frontend`
- Start both: `npm run dev`

## Backend

- Configure `backend/.env` or use `backend/.env.example`
- Default server: `http://localhost:3000`

## Frontend

- Default client: `http://localhost:5173`
